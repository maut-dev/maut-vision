# Maut Vision branding

The brand files live in `public/brand` and ship with the interface; this description is not part of the build.

- `logo-full.png` — the full logo with the "MAUT VISION" lettering. It is shown only on the startup and loading screens; the crop is set
  in `startup.css`.
- `logo-mark.png` — the mark without lettering on a transparent background: four white corner brackets and a lime centre square. The
  sidebar, the window, the tray and the Windows application icon use it.

The same artwork is used for the repository banner in `docs/assets`.
